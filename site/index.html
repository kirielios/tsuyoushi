Troubleshooting

Covers not loading, a source behind Cloudflare, videos that won't play. Here's what to try.

Fix it

Three steps

  1. Copy the repo URL

    It's the box above. It always points at the newest build.

  2. Add it to your reader

    In NeetShelf: Settings → Extension repos, paste, Add.

  3. Install sources

    Browse → Extensions, pick what you read. Updates arrive on their own.

Outdated or empty list? These are JavaScript bundles for web readers, not APKs. Mihon, TachiyomiSY and Komikku can't install them; use Keiyoushi's own repo there.

Tsuyoushi hosts no content. Each extension tells a reader how to fetch a site's public pages, on the reader's own device. Not affiliated with Keiyoushi, Aniyomi or Mihon. Credit for the original extensions goes to their contributors.
